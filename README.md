# 片付けの一歩

片付けの最初の一歩と、毎日の小さな習慣化を支えるモバイルファーストのPWAです。iPhoneとGoogle Pixelのブラウザで使え、ホーム画面へ追加するとアプリのように起動できます。

## 主な機能

- 目標時間を設けないストップウォッチで、片付け開始のきっかけを作る
- 場所、片付けた内容、任意メモを記録
- 連続日数、今月の日数、直近7日、月間カレンダーを表示
- 実際の片付けを7日連続で記録するたび、リカバリー権を1回付与
- リカバリー権による過去の空白日の保護
- 短期・中長期・特別チャレンジに分かれた20種類のバッジ（最長30日連続）
- 場所・片付け内容の追加、編集、並べ替え、アーカイブ
- 片付け後の部屋写真を淡い固定背景または5〜10秒間隔の自動切替背景として表示
- JSONバックアップの書き出しと全置換復元
- オフライン起動

## データについて

記録はサーバーへ送信せず、利用中のブラウザ内（IndexedDB、利用できない場合はlocalStorage）だけに保存します。GitHub Pagesへアプリを公開しても、個人の記録がGitHubへ保存・公開されることはありません。

ブラウザデータの削除、端末の故障、アプリを別の方法で再インストールした場合には記録を失う可能性があります。設定画面から定期的にJSONバックアップを保存してください。異なる端末間の自動同期は初版にはありません。

復元できるJSONは5MBまでです。復元前にスキーマ、日付、タイムゾーン、記録とマスタ・計測の参照、リカバリー履歴を検証し、不正なファイルでは現在のデータを置き換えません。開発初期のschema 0形式は自動的に現行形式へ移行します。

## ローカル開発

必要環境：Node.js 22.13以降

```bash
npm ci
npm run dev
```

品質確認：

```bash
npm test
```

`npm test` はドメインテスト、型検査、Lint、本番ビルド、PWA成果物テストを実行します。

## GitHub Pagesへの公開

1. このフォルダをGitHubリポジトリへpushします。
2. リポジトリの `Settings` → `Pages` を開きます。
3. `Build and deployment` のSourceで `GitHub Actions` を選びます。
4. `main` ブランチへのpush時に、同梱のワークフローがテストと公開を実行します。

Viteのアセットパス、Web App Manifest、Service Workerはリポジトリ配下のサブパスで動くよう相対URLにしています。

## iPhoneへのインストール

1. Safariで公開URLを開きます。
2. 共有ボタンを押します。
3. 「ホーム画面に追加」を選びます。
4. 「Webアプリとして開く」が表示される場合は有効にして追加します。

## Google Pixelへのインストール

1. Chromeで公開URLを開きます。
2. メニューから「アプリをインストール」または「ホーム画面に追加」を選びます。

## 重要な仕様

- 同日に複数件記録しても、片付け日と連続日数は1日分です。
- リカバリー権は7日目の日付を一意に記録し、同日の追加記録・編集・再読み込みでは重複付与しません。
- リカバリー日は表示上の連続を守りますが、次の権利獲得に必要な実片付け7日には含みません。
- ストップウォッチの長さは、連続日数、権利、バッジの条件には使いません。
- 報酬履歴の不整合を避けるため、その日の最後の1件は削除できず、編集のみ可能です。
